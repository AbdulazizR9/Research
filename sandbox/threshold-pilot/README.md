# Threshold Cascade Learning Pilot

## Purpose

This directory preserves and tests the Linear Threshold prototype originally
created in the separate `abm` repository.

The purpose of this pilot is to understand:

- synchronous and asynchronous updating;
- irreversible activation;
- random network generation;
- threshold distributions;
- initial active seeds;
- repeated stochastic simulations;
- result recording and reproducibility.

## Status

This is a learning pilot, not the final research model.

No scientific novelty, empirical validity, or real-world interpretation is
currently claimed.

## Provenance

The initial `main.cpp` was copied unchanged from the former local repository:

`abm/lt/main.cpp`

The separate repository may be deleted after this copy is verified, committed,
and successfully executed.
