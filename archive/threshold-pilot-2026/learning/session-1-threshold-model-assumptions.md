# Study Time — Session 1

## 1. Synchronous and asynchronous updates

В текущей модели используется **synchronous update**, то есть обновление по отдельным раундам или шагам.

Во время одного шага все агенты принимают решения на основе одного и того же старого состояния системы. Новые активированные агенты записываются в `next_active` и не влияют на других агентов до следующего шага.

Даже если агенты проверяются последовательно или в случайном порядке, обновление остаётся synchronous, пока все они смотрят на старый массив `active`.

При **asynchronous update** изменения применяются сразу. Агент, активированный раньше в текущем проходе, уже может повлиять на агентов, которые будут проверяться позже. Поэтому результат может зависеть от порядка обновления.

## 2. Reversibility and irreversibility

В текущей модели возможен только переход:

\[
0 \rightarrow 1
\]

Обратный переход:

\[
1 \rightarrow 0
\]

не реализован. Следовательно, динамика является **irreversible**.

Число активных агентов не может уменьшаться:

\[
A(t+1) \geq A(t)
\]

На следующем шаге активных агентов будет либо больше, либо столько же.

Если моделируемая система допускает отказ от решения, восстановление или возвращение в прежнее состояние, для этого нужно отдельно добавить обратный переход.

## 3. Random graph and parameter `p`

Для каждой пары агентов программа генерирует случайное число:

```cpp
uni(rng)
```

Если выполняется условие:

```cpp
uni(rng) < p
```

между агентами создаётся ребро.

Параметр `p` отвечает за вероятность появления связи между двумя агентами. Чем выше `p`, тем плотнее сеть и тем больше соседей в среднем имеет каждый агент.

Разные random seeds могут создавать разные сети, поэтому при одинаковых значениях `N` и `p` cascade может развиваться по-разному.

## 4. Thresholds

`Threshold` — это условие, которое должно быть выполнено, чтобы неактивный агент активировался.

У каждого агента имеется собственное threshold-значение. В текущем коде thresholds случайно распределяются между 0 и 1:

\[
\theta_i \sim U(0,1)
\]

Агенты с низким threshold активируются легче, а агенты с высоким threshold требуют большей доли активных соседей.

Если все thresholds установить равными `0.9`, распространение обычно станет сложнее. Однако итог также зависит от topology и количества соседей. Внутри тесно связанной активной группы распространение ещё возможно, но на границе cascade может остановиться, если у внешних агентов недостаточно активных соседей.

## 5. Initial seeds and randomness

Параметр `k` задаёт количество агентов, которые являются активными в начале симуляции.

Эти initial seeds выбираются случайно. На результат влияет не только их количество, но и положение в сети:

- находятся ли они рядом;
- имеют ли общих соседей;
- находятся ли среди хорошо связанных узлов;
- распределены ли они по разным частям сети.

Одного запуска недостаточно, потому что случайными являются:

- структура сети;
- thresholds;
- расположение initial seeds.

Поэтому для эксперимента нужны повторные запуски с разными seeds и анализ распределения результатов.
